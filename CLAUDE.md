# Shiply Core 2.0

A new, standalone system for **Shiply: next-day parcel delivery**.

- `GOAL.md`: **the end goal, fixed.** Read it first and check every piece of work against it.
  Never reopen a decision in its log unless the owner asks.
- `PLAN.md`: steps and the owner's open decisions.
- `shiply-merchant-portal.html`: the clickable merchant portal mockup (sample data). It is the
  visual and behaviour reference.

## Rules for this folder
1. **Shiply only.** Shiply Now (60-minute delivery) is a separate product and is not built here.
2. **No code from earlier versions.** Never copy, import or merge code from `../shiply`,
   `../shiplynow-finance`, `shiply-core/` or the `ShiplyNow` branch. Their docs may be read to
   recall a business rule; confirm the rule with the owner before using it.
3. **Design first.** Every screen is a clickable mockup approved by the owner before it is built,
   and the built screen must match it.
4. **One part at a time**, finished, tested and checked by the owner in the browser before the next.
5. Behave like Bosta's merchant portal, look like Shiply. Never use another company's colours,
   fonts, logo or style.

Brand: Shiply Brand Manual in `~/Downloads/Shiply` (Deep Navy #10243A, Electric Blue #174BFF,
Lime #DFFF00 for highlights only, Creamy White #FFF8ED, Baby Blue #A5E8F5; Plus Jakarta Sans and
IBM Plex Sans Arabic).
